
已实现语音交互播放，

1.装库文件,发现不用重新提交镜像也行，库文件掉电不会消失
联网，然后在镜像内执行：
apt-get update && apt-get install -y alsa-utils
安装后，建议在容器内用 aplay -l  检查声卡是否识别。

2.更改了asr_node.py，voice_play.py两个程序，分别把这两个程序放到src/xf_mic_asr_offline/scripts和src/xf_mic_asr_offline/xf_mic_asr_offline下替换原来文件，重新build。


其他模块如voice_control_move.py 如何使用语音播放函数：

# 在 voice_control_move.py 中添加
from xf_mic_asr_offline.voice_play import play

# 然后在需要播放语音的地方调用
# play('go')  # 播放 go.wav
# play('back')  # 播放 back.wav
# play('turn_left')  # 播放 turn_left.wav
